# Xiaohongshu layout language

Use these stable Markdown forms directly:

- `# 大标题` for a card-opening conclusion.
- `## 小标题` for a section or numbered step.
- `**重点**` for the single strongest conclusion on a card.
- `{{color:#RRGGBB|文字}}` for sparse key phrases.
- `{{bg:#fff3a3|文字}}` for numbers, results and turning points.
- `> 引用` for a short opinion or source sentence.
- `[[pagebreak]]` to deliberately begin a new card.
- `[[image:图片ID]]` to preserve an existing image position.

Prefer one main visual emphasis per paragraph. Do not highlight full paragraphs. Keep each card internally coherent and place page breaks at topic transitions rather than at arbitrary character counts.
